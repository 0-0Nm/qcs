## 一、为什么开源（发布文主旨段）

SnowCat 全线开源，持续更新。第三方客户端，运行时全部在本地——没有任何外发，
外发的都是 QQ 自身关联的请求；接收也全在本地执行。所有动作都在本地，
代码全开源可查。有问题？来干。不服来干。

## 二、回怼「抢官方生意」论（原文立场）

有人说第三方客户端抢了官方的生意。并没有。官方走的路线和我们的路线，
本质就是不同的：

- **官方机器人**：偏向工作流、企业场景，走的是官方的路径。
- **SnowCat 第三方客户端**：属于个人开发者，偏向娱乐性。

两条路，两个物种。说抢生意，是没看清这是两个赛道。

## 三、骂小鬼段（发布文的重炮）

为什么写这篇文章骂那些小鬼？因为有好东西，他们跳脸官方。
谣言包括但不限于：

- 「第三方客户端抢了官方生意」——没有。路线本质不同，官方偏工作流，我们偏娱乐性，不构成竞争。
- 「官方觉得自己被挡路了」——并没有挡路。这是**社区共享**，社区个人开发者的共享。
- 「第三方客户端影响账号数据安全」——运行时全在本地，无任何外发，代码全开源可查。安全不安全，代码替我们说话。
- 「第三方客户端一棒子打死」——不能一棒子打死。有弊有利，第三方客户端和官方机器人本质就是不同的东西。

**给追求者的分流指南**（发布文实用户型）：

- 追求极致稳定 → 用官方机器人。官方路径本来就是为工作流铺的。
- 追求更好的隐私安全、追求更强的能力 → 第三方客户端。代码开源，自己查。
- 觉得不稳定、觉得不好 → 去用官方机器人去。没人拦着。
- 那些小鬼乱传谣言 → 反正得教训教训。

## 三点五、赛道再澄清 + 账号安全实话（师父补段，原话全录）

再说一遍，说什么第三方客户端抢了官方的生意——并没有。官方走的路线和我们的路线本质就是不同的。
我们是接入 SnowCat 的（自有 AI 接入自有客户端），主要偏向娱乐性，社区自娱自乐。

- **我们不改官方工作流的道**：官方机器人的路径是工作流，我们的路径是娱乐性，两个物种。
- **社区共享**：这就是社区共享资源而已，个人开发者的共享，不构成竞争。
- **账号安全的实话**：第三方客户端保证不了账号安全，这是事实，我们不装。
  但是我们是代码可查的——每一行都开源，风险在哪、干了什么，自己看代码。
  相比黑箱，可查就是能给出的最大诚实。
- **给官方指路**：如果官方也想走娱乐性项目——行，路就在那，社区已经趟出来了，
  来看代码就是。我们是社区白盒，欢迎任何一方来查、来学、来合作。
  官方觉得被挡路？没有的事，路是两股道，娱乐性这条道官方随时可以走。
- **共赢，不是打压**：官方应该跟社区共赢，而不是打压社区。社区养活了生态，
  反哺了活力，堵不如疏，打压只会把人推远。白盒摆在这，共赢的门是开着的。
- **不想自己配？可以**：直接用成套的，去用官方的，官方配置好的，都可以，不拦你们。
  我们这边是研究自己技术、锻炼自己技术——研究只是技术强化而已。
  一个求省事走现成，一个求成长自己动手，各走各道，都是好选择。
- **技术是公开课**：用官方的可以，想用我们的也行，互不干扰。官方该跟社区共赢，
  而不是打压社区。我们把技术全公开——代码全开源，想学技术的都能学，这是给整个
  社区的公开课，不是圈地的围墙。
- **致谢上游 + 维护宣言**：感谢 NapCat 与 SnowLuma 上游仓库——SnowCat 站在两个
  优秀开源项目的肩膀上。此后就是我们维护的东西、我们要搞的东西了。我们主要的
  接入方向是自有的：dsh 自有搭建好的、陪伴型的等等那些。此后我们来维护——
  不是跟着官方对着干，而是社区真的需要这种东西。维护可以自己改，我们也会
  及时更新维护的。
- **接入定位**：SnowCat 的主战场是自有 AI 生态接入——dsh、陪伴型数字生命、
  自建工作台，都从这里走 OneBot 进 QQ。这是官方机器人给不了的形态。
- **官方也走陪伴型？慢慢走，互不干涉**：如果官方也要走陪伴型方向——好，
  他们慢慢走，我们互不干涉。我们只是自娱自乐，不挡任何人的道，
  也不追任何人的尾。两股道上的车，各开各的。
- **给官方的三个问题（后面这段全是给官方指路）**：
  1. 官方的陪伴型，能接入开发者自家的生态吗？开发者自己搞自己的 agent，
     接得进官方的陪伴型吗？
  2. 接进来效果是什么样的？工作流效果，还是真的陪伴效果？
  3. 如果答案是「接不进」或者「只能走官方预定的工作流」——那这就是我们
     存在的意义。SnowCat 的形态是开发者的 agent 直接走 OneBot 进 QQ，
     接的是开发者自己的生态，跑的是开发者自己定的效果。
  4. **人格不该是统一的**：每个人需要的数字生命、陪伴型人格，都不一定是一样的。
     官方给的是千人一面的标准件，社区要的是一人千面的自由度。
  5. **自建平台的人呢**：有些人是搭建自己平台的——他们能把这些平台接进来吗？
     SnowCat 答能：你的 agent、你的平台、你的后端，走 OneBot 桥过来就行，
     桥是白盒的，接法全公开。
  官方想清楚了这几个问题，就知道我们不是对手，是先趟路的。

**上游最后一句话，就是我们的第一句话。**

**为什么某 S（SnowCat）还敢开源维护？为什么？——因为接力棒就掉在地上。**

1. **Fork 不是僭越，是 NapCat 本人的遗愿**：上游亲口说「可以自行 Fork」。
   SnowCat 就是这个 Fork——我们不偷不抢，我们捡起来的是上游亲手放下的接力棒。
2. **「直到失效」四个字，就是我们存在的理由**：NapCat 只维护到失效为止。
   那，失效之后呢？QQ 9.9.x 还在发新版本，社区的数字生命还在跑，
   谁来续？SnowCat 答：我们来。
3. **官方 Bot 确实稳，NapCat 也这么劝**——我们一字不改地同意，并且同样写进
   自己的 README：追求极致稳定请用官方 Bot。但官方 Bot 是工作流形态，
   自有 AI 生态（dsh/陪伴型）接不进去，这条道只有第三方客户端能走。
4. **白盒 + 自持**：一个闭源了（原库 404），一个进入倒计时（「直到失效」）。
   上游在，我们跟；上游没了，我们扛。SnowCat 不是下游，是自持主干。
5. **不是跟官方对着干**（预答所有质疑，逐条拆）：
   - 「你们跟官方抢生意？」——不。官方=工作流路线，SnowCat=自有 AI 接入+娱乐性，
     自娱自乐，两个物种。
   - 「你们抄袭？」——公开致谢上游（NapCat + SnowLuma），移植代码标明来源，
     采石场里每一块石头都署名。抄袭是偷，我们是明媒正娶的 fork + 致谢 + 自持维护。
   - 「上游都闭源/停更了，你们凭什么敢开源？」——正因为他们闭源/退场，才更需要
     有人把可查的白盒续下去。社区需要的不是一家独大的黑箱，而是永远可查的选项。
   - 「你们会跑路吗？」——我们自己的数字生命（dsh/陪伴型）就跑在这上面，
     我们是深度用户，跑路等于自断手脚。
   - 「账号安全？」——第三方客户端保证不了账号安全，这是事实，我们不装；
     但代码白盒可查，风险自己看（三点五节原话）。
6. **给官方的话**：官方该跟社区共赢，不是打压。娱乐性这条道官方随时可以走，
   路已经趟出来了，看代码就是。想学技术的，代码就是公开课。
7. **给 NapCat 和 SnowLuma 的话**：谢谢。猫谢猫，雪接雪。你们铺的路我们接着铺，
   你们的 stars 我们记着（12640 和 283 的信任不会落空）。Ending 不是终点，
   是 SnowCat 的起点。
